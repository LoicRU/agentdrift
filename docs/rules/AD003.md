# AD003 — package-manager-mismatch

Default severity: **warn**

The instructions use a package manager (npm, pnpm, yarn, bun) different from the one the repo uses, according to the `packageManager` field in `package.json`, or else the lockfile.

## Bad

```md
Install with `npm install`.   <!-- repo has pnpm-lock.yaml -->
```

## Good

```md
Install with `pnpm install`.
```

## Disable

One line: `<!-- agentdrift-disable-next-line AD003 -->`

Everywhere: `{ "rules": { "AD003": "off" } }` in `.agentdrift.json`.

Notes: if several lockfiles coexist the rule stays silent. Global installs (`-g`, `--global`) are ignored.
