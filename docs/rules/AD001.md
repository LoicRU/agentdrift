# AD001 — missing-path

Default severity: **warn**

A path cited in the instructions does not exist in the repository. Agents waste time looking for files that were moved or deleted.

## Bad

```md
Business logic lives in `src/legacy/`.   <!-- folder deleted months ago -->
```

## Good

```md
Business logic lives in `src/core/`.
```

## Disable

One line: `<!-- agentdrift-disable-next-line AD001 -->`

Everywhere: `{ "rules": { "AD001": "off" } }` in `.agentdrift.json`.

Notes: paths are resolved from the repo root and from the file's folder. Generated folders (`dist`, `build`, `node_modules`, `coverage`, `.next`, `target`…) are ignored. Placeholders (`<name>`), globs (`*`) and URLs are never checked.
