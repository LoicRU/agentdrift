# AD004 — runtime-version-mismatch

Default severity: **warn**

A Node, Python or Go version cited in the text differs from the declared one (`.nvmrc`, `.node-version`, `.python-version`, `.tool-versions`, `engines.node`, `requires-python`, `go.mod`).

## Bad

```md
Requires Node 18.   <!-- .nvmrc says 22 -->
```

## Good

```md
Requires Node 22.
```

Notes: `Node 18+` and `Node >= 18` are minimums: reported only if the declared version is lower. For declarations that are themselves minimums (`engines`, `requires-python`, `go.mod`), only a cited version *below* the minimum is reported. Node is compared by major version, Python and Go by major.minor.

## Disable

One line: `<!-- agentdrift-disable-next-line AD004 -->`

Everywhere: `{ "rules": { "AD004": "off" } }` in `.agentdrift.json`.
