# AD005 — broken-reference

Default severity: **error**

A relative Markdown link or an `@file` import (as used by `CLAUDE.md`) points to a file that does not exist.

## Bad

```md
See [the guide](docs/guide.md).   <!-- file was renamed -->
@docs/missing.md
```

## Good

```md
See [the guide](docs/contributing.md).
@docs/contributing.md
```

Notes: links are resolved relative to the file that contains them. URLs, anchors (`#section`) and absolute paths are ignored; the `#fragment` and `?query` parts are stripped before checking.

## Disable

One line: `<!-- agentdrift-disable-next-line AD005 -->`

Everywhere: `{ "rules": { "AD005": "off" } }` in `.agentdrift.json`.
