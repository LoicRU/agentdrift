# AD002 — missing-script

Default severity: **error**

A command such as `npm run X`, `pnpm run X`, `yarn run X`, `bun run X` or `make X` refers to a script or target that is not defined in `package.json` or the `Makefile`. This is the most common and most costly drift.

## Bad

```md
Run `npm run test:unit` before pushing.
```
```text
AGENTS.md:1  error  AD002  Script "test:unit" not found in package.json.
                            Did you mean "test" or "test:e2e"?
```

## Good

```md
Run `npm test` before pushing.
```

Notes: in a monorepo the closest `package.json` is used first, then parent folders. If there is no `package.json` (or no Makefile), nothing is reported. `npm start` is never reported (it has a default).

## Disable

One line: `<!-- agentdrift-disable-next-line AD002 -->`

Everywhere: `{ "rules": { "AD002": "off" } }` in `.agentdrift.json`.
